# Skill: generador-readme

Genera un README.md completo analizando la documentación
del proyecto (carpeta `.github/copilot` y
`copilot-instructions.md`).

## Pasos

1. Revisa los archivos de `.github/copilot`: Architecture,
   Code_Exemplars, Coding_Standards,
   Project_Folder_Structure, Technology_Stack,
   Unit_Tests, Workflow_Analysis.
2. Revisa `copilot-instructions.md`.
3. Crea el README con estas secciones: nombre y
   descripción, stack tecnológico, arquitectura,
   primeros pasos, estructura del proyecto, funciones
   principales, flujo de desarrollo, estándares de
   código, pruebas, cómo contribuir, licencia.

## Formato

- Markdown con encabezados claros, bloques de código,
  listas, enlaces a la demás documentación y badges
  si hay datos.
- Conciso pero informativo: lo que un desarrollador
  nuevo o un usuario necesita saber.
