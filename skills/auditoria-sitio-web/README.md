# Skill: auditoria-sitio-web

**Auditorías de sitios web por CLI para humanos, agentes y LLMs**

## ¿Qué es squirrelscan?

[squirrelscan](https://squirrelscan.com) es una herramienta completa de auditoría de sitios web, diseñada para desarrolladores, profesionales de SEO y asistentes de programación con IA. Creada para integrarse sin fricción en flujos de desarrollo modernos y entornos de programación asistida por IA.

**Características:**
- Más de 260 reglas de auditoría en SEO, rendimiento, accesibilidad, contenido, seguridad y más
- Detección de secretos filtrados (96 patrones: OpenAI, Anthropic, AWS, Stripe y más)
- Múltiples formatos de salida: console, text, json, markdown, llm, html
- Informes de diferencias (diff) para regresiones entre auditorías
- Diseñada tanto para desarrolladores humanos como para agentes de IA
- Optimizada para pipelines de CI/CD y automatización
- Salida nativa para LLM, pensada para depuración y optimización asistidas por IA

Ya sea que depures problemas de SEO, valides la salud del sitio o permitas que tu asistente de IA corrija problemas del sitio de forma autónoma, squirrelscan encaja en tu flujo de trabajo.
